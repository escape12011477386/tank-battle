# 坦克大战 Battle City 🎮

一个用原生 HTML + Canvas + JavaScript 编写的经典《坦克大战》（Battle City）网页游戏，单文件、零依赖，打开即玩。

## ✨ 特性

- 经典玩法：保护你的基地（鹰），消灭所有敌方坦克
- 4 种敌方坦克：普通、快速、火力、装甲
- 可破坏的砖墙、不可破坏的钢墙、水域、草丛（可藏身）
- 4 种道具：★ 火力升级、护盾、生命 +1、冰冻敌人
- 关卡推进，敌人数量与强度随关卡提升
- 计分与最高分本地存档（localStorage）
- 简单的音效（WebAudio 合成，无外部音频文件）

## 🕹️ 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 移动 |
| 空格 | 射击 |
| M | 静音 |
| P | 暂停 |
| Enter | 开始 / 下一关 / 重新开始 |

## 🚀 如何运行

直接双击打开 `index.html` 即可在浏览器中游玩，无需任何构建工具或依赖。

## 🌐 在线游玩（GitHub Pages）

1. 进入仓库的 **Settings → Pages**
2. 在 **Source** 中选择 `main` 分支
3. 保存后访问 `https://<用户名>.github.io/tank-battle/` 即可在线游玩
